# Support

Agent on Azure is open source, maintained in the open by Impact AI, without a service level. Repository issues are read and triaged on a best-effort basis, with no guaranteed response, fix or delivery date. Support for a deployed or customized application is available only under a separate paid contract, whose terms define the scope and any service levels.

- **A bug or a question about Agent on Azure**: open an issue in this repository from the bug report form, with the azd version, the deployment mode (demo or hardened), and the output of the step that failed. Secrets, subscription ids and resource names belong in no issue.
- **Deploying it**: [docs/deployment.md](docs/deployment.md) and its troubleshooting table cover what has gone wrong before.
- **Operating it**: [docs/operations.md](docs/operations.md) — the smoke test, log queries, tuning live, backups.
- **An Azure service**: open a support request in the Azure portal; the services are Microsoft's.
- **A security problem**: see [security policy](SECURITY.md), not an issue.
- **Paid implementation or support**: Impact AI offers both separately from this repository; get in touch through [impact.ai](https://impact.ai).
